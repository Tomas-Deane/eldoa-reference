# ELDOA Spinal Index

A minimal visual reference for spinal ELDOA exercises and the related video index.

## Structure

- `app/atlas.ts` — exercise, spine, filter, and video data
- `app/page.tsx` — page layout, filtering, and scroll tracking
- `app/spine-navigator.tsx` — interactive SVG spine
- `app/globals.css` — all styling
- `public/` — production images and spine SVG
- `docs/` — standalone GitHub Pages mirror

## Commands

```bash
npm install
npm run dev
npm run build
npm run lint
```
